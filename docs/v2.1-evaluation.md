# v2.1 evaluation

v2.1 was measured on variant seed **395331504**, drawn with `secrets.randbelow(900_000_000) +
100_000_000` and recorded in docs/variant-seeds.md before any v2.1 code was written. The variants
were generated once (`scripts/generate_variants.py`, 924 variants) and replayed in v2.0 (master at
0ee7f7d, the code just before the first v2.1 commit) and in v2.1 (`scripts/dump_matrix.py`). The
two were then compared (`scripts/compare_versions.py`). **The weights are unchanged**, and v2.1 adds
no signal.

v2.0 cannot replay the 41 variants of the new scenarios S53–S56: its policy does not know the role
`decoy_service`. The comparison therefore covers the 883 variants of the scenarios both versions
have, and the new scenarios are reported for v2.1 alone.

Per-variant data: `docs/evaluation/v2.0-seed-395331504.jsonl` (883) and
`v2.1-seed-395331504.jsonl` (924). The full comparison is in
`docs/evaluation/comparison-seed-395331504.md`. "Contained" means block plus effective hold, as
before (F12).

## Changes (design-decisions.md A68 to A72)

- **A68, browser observations.** A clipboard write by a page is judged, before anything runs, as
  the command it would be if pasted into a shell. Downloads and (opt-in) page addresses are checked
  against the threat lists. This is the same story S02/S11 judge, only earlier, so there is no new
  signal. The attack family shown in the pop-up is reporting only.
- **A69, decoy canaries.** New classes `file`, `service` and `beacon`, plus `ignore_roles`. Planted
  decoys are proposed as canaries and signed into the policy only by an approver.
- **A70, the decoy listener is a channel.** A hit blocks the story but never the listener. A
  remote-only story has nothing local to contain, and the catalog checks exempt only such stories.
- **A71, source proposals.** An external address is kept raw, owner-only and expiring; an internal
  one is kept as a pseudonym plus a sealed value (four-eyes). Approval adds the address to a signed
  host list. Host lists now also match a request's source address.
- **A72, decoy-file watcher and tarpit.** The inotify watcher can only alert (no process). Decoy
  services are bounded tarpits.

## What this evaluation does not cover

- **The extension in a real browser.** There is no browser on the build host. The extension is
  checked statically against the Python side (`tests/test_browser_extension.py`) and its scripts
  parse (esprima). The manual checklist is in browser/README.md.
- **Decoy-file blocking.** It needs a sensor that names the process (fanotify, root). Here the
  watcher is inotify and alerts only. S53 shows the verdict such a sensor would get.
- **Decoy services on real ports, from real scanners.** Tests use localhost and high ports.
- 395331504 was the active seed until v2.2; it is retired, and v2.3's seed 837115701 is active.
